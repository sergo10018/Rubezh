# Проверка согласованности

Реестр `docs/registry/facts.yaml` хранит факты, которые встречаются в нескольких местах, и говорит, какой источник главный. Эта проверка только ищет и сообщает. Ничего не исправляй, пока пользователь не согласится.

## Что проверять
- Без уточнения: весь реестр.
- С именем: одну запись (`/consistency-check Аптечка малая`). Нет такой записи — назови похожие и остановись.
- `изменения`: только записи, которых касаются файлы из `git diff HEAD~1 --name-only` и незакоммиченных правок.

Реестра нет или он пуст, либо проверять нечего — вердикт **НЕ ПРОВЕРЕНО** с причиной. Это не значит «всё хорошо».

## Как проверять
1. Прочитай реестр. Записи `status: deprecated` не сверяй, но если устаревшее значение где-то ещё используется, сообщи.
2. Для каждой записи открой `source` и убедись, что `value` совпадает с ним. Ссылка `файл#N` означает раздел N. Источник не найден — это находка.
3. Проверь каждый файл из `referenced_by`. Затем поищи название через Grep в `docs/gdd`, `docs/01_Канон.md`, `docs/narrative`, `docs/levels`, `data` и `CLAUDE.md`: файлы могли появиться позже реестра. Читай только нужный участок, а не весь документ. Для кода смотри константы в `Public/**/*Rules.h`, `RubezhEncumbrance.h`, `RubezhSettings.h`.
4. Сравни смысл, а не написание: `900 с` и `15 минут` совпадают. Разные единицы приводи к одной. «Не упомянуто» — не расхождение.
5. Отдельно поищи в новых текстах названия фракций, не совпадающие с реестром, и запрещённое каноном: мутанты, аномалии, артефакты, лабораторные организмы, «Глубинные». Упоминание в самом запрете нарушением не считается.

## Как сообщать
Объясняй простыми словами: владелец проекта — новичок в UE.

```
Проверено: <N> записей. Вердикт: СОШЛОСЬ / ЕСТЬ РАСХОЖДЕНИЯ / НЕ ПРОВЕРЕНО

Расхождения
1. <Факт>
   Главный источник (<файл>): <значение>
   Отличается (<файл:строка>): <значение>
   Что это значит для игры: <одна фраза>
   Предложение: <что поправить>

Устаревшая запись в реестре: <если реестр отстал от источника>
Уже известно, не решено: <записи с conflict, которые всё ещё в силе>
Новые кандидаты в реестр: <факт встретился минимум в двух местах, но не занесён>
Не удалось проверить: <что и почему>
```

Не пиши «СОШЛОСЬ», если есть непроверенные записи: укажи их. Известный `conflict` остаётся расхождением, пока он не решён, поэтому вердикт тогда — ЕСТЬ РАСХОЖДЕНИЯ.

## Что можно исправлять после согласия
- **Реестр:** только с согласия пользователя. Заполни `revised`, старое значение запиши в `note`, снятый `conflict` удали.
- **Канон:** только с одобрения лид-геймдизайнера и с записью в журнал изменений канона.
- **GDD и правила игры:** решает лид-геймдизайнер. Какое значение верное, определяет он, даже если главный источник говорит иначе.
- **`data/*.csv`:** после правки в редакторе нужен переимпорт таблицы. Напомни об этом.
- **Код (`*Rules.h`):** передай `unreal-specialist`; после правки — сборка и автотесты.
- **`.uasset` и `.umap`:** файлами не правим.
