# tools/reels — сборка рилсов

Нужны `python` 3.10+ и `ffmpeg` в PATH. Всё работает локально.

## 1. Тайминг сценария до съёмки
```bash
python tools/reels/beats_ru.py script.txt --target 25 --srt subs.srt
```
Одна строка = одна фраза. Флаги: хук > 3 с, бит > 4 с, три строки без конкретики, нет закольцовки, длина не совпадает с целью. `--srt` пишет черновые субтитры по оценке темпа (после записи озвучки таймкоды нужно подогнать под реальную речь).

## 2. Сборка
```bash
python tools/reels/make_reel.py marketing/reels/01/edit.json
```
Монтажный лист JSON — формат в шапке `make_reel.py`. Делает: нарезку по таймкодам, кадр 9:16 (кроп или размытый фон для горизонтальной записи экрана), ускорение, фото с наездом, текстовые карточки и субтитры в безопасной зоне Reels, музыку + озвучку, нормализацию громкости до −14 LUFS, экспорт 1080×1920 H.264/AAC 30 fps.

## Куда класть
```
marketing/reels/NN_название/
  raw/        исходники от команды (телефон, вертикально, 30 fps)
  script.txt  сценарий из docs/marketing/02_Сценарии_рилсов.md
  subs.srt
  edit.json
  out/        готовый ролик → публикует человек
```
Исходники тяжёлые: `marketing/reels/*/raw` и `out` не класть в VCS без LFS.
